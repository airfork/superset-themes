# Code of Conduct

## Expected Behavior

Be respectful, specific, and constructive. Discuss ideas and implementation details directly without personal attacks, harassment, or discriminatory language.

## Unacceptable Behavior

Unacceptable behavior includes threats, harassment, sustained disruption, doxxing, sexualized comments or imagery, and abuse based on identity, background, ability, or beliefs.

## Reporting

Report conduct concerns through GitHub by contacting the repository owner or, when the concern is security-sensitive, by using private vulnerability reporting.

## Enforcement

The repository owner may remove comments, close issues or pull requests, block contributors, or take other moderation steps needed to keep the project workable.
